## 一、核心接口函数一览

### 服务端（Server 端）

| 接口 / 装饰器 | 说明 | 所在模块 |
|---|---|---|
| `MCPServer(name, ...)` | 创建高层 MCP 服务器实例 | `mcp.server.mcpserver` |
| `@mcp.tool()` | 注册一个 Tool（工具），LLM 可调用 | `MCPServer` 方法 |
| `@mcp.resource(uri)` | 注册一个 Resource（资源），支持静态 URI 和模板 URI | `MCPServer` 方法 |
| `@mcp.prompt()` | 注册一个 Prompt（提示模板） | `MCPServer` 方法 |
| `mcp.run(transport=...)` | 启动服务器（stdio / sse / streamable-http） | `MCPServer` 方法 |

### 客户端（Client 端）

| 接口 / 函数 | 说明 | 所在模块 |
|---|---|---|
| `Client(server)` | 高层客户端，支持内存直连、URL 连接 | `mcp.client.client` |
| `ClientSession(read, write)` | 底层客户端 Session，用于 stdio/SSE/HTTP 传输 | `mcp.client.session` |
| `stdio_client(params)` | 通过子进程 stdio 管道连接 MCP 服务器 | `mcp.client.stdio` |
| `streamable_http_client(url)` | 通过 HTTP+SSE 连接 MCP 服务器 | `mcp.client.streamable_http` |
| `sse_client(url)` | 通过 SSE 连接 MCP 服务器 | `mcp.client.sse` |

### 常用类型

| 类型 | 说明 |
|---|---|
| `StdioServerParameters` | stdio 传输参数（command、args、env） |
| `CallToolResult` | 工具调用结果 |
| `TextContent` | 文本内容块 |
| `ImageContent` | 图片内容块 |
| `Image` | 高层图片封装（自动处理 base64） |

## 三、场景 1：创建一个最简 Tool 服务器

**场景描述**：创建一个只有一个 `echo` 工具的 MCP 服务器，接收文本并原样返回。

### 代码

```python
# echo_server.py
from mcp.server.mcpserver import MCPServer

mcp = MCPServer("Echo Server")

@mcp.tool()
def echo(text: str) -> str:
    """Echo back the input text"""
    return text

if __name__ == "__main__":
    mcp.run()  # 默认 stdio 传输
```

### 交互示例

```
# 启动开发模式
uv run mcp dev echo_server.py

# 在 MCP Inspector 中：
# 1. 点击 "Tools" 标签页
# 2. 可以看到 "echo" 工具
# 3. 输入参数 {"text": "Hello, MCP!"}
# 4. 点击执行
# 5. 返回结果：[TextContent(type="text", text="Hello, MCP!")]
```

**要点**：
- `@mcp.tool()` 自动从函数签名提取参数 schema
- 函数的 docstring 会作为工具描述
- 返回值会自动包装成 `TextContent`

## 四、场景 2：定义 Resource（静态资源 & 模板资源）

**场景描述**：创建一个提供配置信息和用户数据的资源服务器。

### 代码

```python
# resource_server.py
from mcp.server.mcpserver import MCPServer

mcp = MCPServer("Resource Server")

# 静态资源：固定 URI
@mcp.resource("config://app-settings")
def get_settings() -> str:
    """Return application settings"""
    return '{"theme": "dark", "language": "zh-CN", "version": "1.0"}'

# 模板资源：URI 中含有参数占位符
@mcp.resource("users://{user_id}/profile")
def get_user_profile(user_id: str) -> str:
    """Return user profile by ID"""
    profiles = {
        "001": '{"name": "张三", "role": "admin"}',
        "002": '{"name": "李四", "role": "user"}',
    }
    return profiles.get(user_id, '{"error": "user not found"}')

if __name__ == "__main__":
    mcp.run()
```

### 交互示例

```
# 客户端读取静态资源
await client.read_resource("config://app-settings")
# 返回: ReadResourceResult(contents=[TextResourceContents(
#     uri="config://app-settings",
#     text='{"theme": "dark", "language": "zh-CN", "version": "1.0"}'
# )])

# 客户端读取模板资源
await client.read_resource("users://001/profile")
# 返回: ReadResourceResult(contents=[TextResourceContents(
#     uri="users://001/profile",
#     text='{"name": "张三", "role": "admin"}'
# )])

# 客户端列出可用资源模板
await client.list_resource_templates()
# 返回: ListResourceTemplatesResult(resource_templates=[
#     ResourceTemplate(uri_template="users://{user_id}/profile", name="get_user_profile")
# ])
```

**要点**：
- 静态资源使用固定 URI，如 `"config://app-settings"`
- 模板资源使用 `{param}` 占位符，如 `"users://{user_id}/profile"`
- 模板参数从函数参数自动提取

## 五、场景 3：定义 Prompt 模板

**场景描述**：创建代码审查和翻译助手的提示模板。

### 代码

```python
# prompt_server.py
from mcp.server.mcpserver import MCPServer
from mcp.server.mcpserver.prompts import base

mcp = MCPServer("Prompt Server")

# 简单文本 prompt
@mcp.prompt()
def code_review(code: str, language: str = "python") -> str:
    """Review code and provide suggestions"""
    return f"请审查以下 {language} 代码并提出改进建议：\n\n```{language}\n{code}\n```"

# 返回消息列表的 prompt（支持多轮对话）
@mcp.prompt()
def translate(text: str, target_language: str = "英文") -> list[base.Message]:
    """Translate text to target language"""
    return [
        base.UserMessage(f"请将以下文本翻译为{target_language}："),
        base.UserMessage(text),
        base.AssistantMessage(f"好的，我来将文本翻译为{target_language}。"),
    ]

if __name__ == "__main__":
    mcp.run()
```

### 交互示例

```
# 列出所有 prompts
await client.list_prompts()
# 返回: ListPromptsResult(prompts=[
#     Prompt(name="code_review", arguments=[
#         PromptArgument(name="code", required=True),
#         PromptArgument(name="language", required=False),
#     ]),
#     Prompt(name="translate", arguments=[...]),
# ])

# 获取 prompt 实例
await client.get_prompt("code_review", {"code": "print('hello')", "language": "python"})
# 返回: GetPromptResult(messages=[
#     PromptMessage(role="user", content=TextContent(
#         text="请审查以下 python 代码并提出改进建议：\n\n```python\nprint('hello')\n```"
#     ))
# ])
```

## 六、场景 4：使用 Client 连接并调用 Server

**场景描述**：使用高层 `Client` API 以内存方式直连服务器，适用于测试和简单集成。

### 代码

```python
# test_server.py
import anyio
from mcp.client.client import Client
from mcp.server.mcpserver import MCPServer

# 创建服务器
mcp = MCPServer("Calculator")

@mcp.tool()
def add(a: int, b: int) -> int:
    """Add two numbers"""
    return a + b

@mcp.tool()
def multiply(a: int, b: int) -> int:
    """Multiply two numbers"""
    return a * b

@mcp.resource("math://pi")
def get_pi() -> str:
    return "3.14159265358979"

async def main():
    # Client(server) 内存直连，无需传输层
    async with Client(mcp) as client:
        # 列出工具
        tools = await client.list_tools()
        print("可用工具：")
        for tool in tools.tools:
            print(f"  - {tool.name}: {tool.description}")

        # 调用工具
        result = await client.call_tool("add", {"a": 3, "b": 5})
        print(f"\n3 + 5 = {result.content[0].text}")  # "8"

        result = await client.call_tool("multiply", {"a": 4, "b": 7})
        print(f"4 × 7 = {result.content[0].text}")  # "28"

        # 读取资源
        resource = await client.read_resource("math://pi")
        print(f"\nπ = {resource.contents[0].text}")

anyio.run(main)
```

### 交互输出

```
可用工具：
  - add: Add two numbers
  - multiply: Multiply two numbers

3 + 5 = 8
4 × 7 = 28

π = 3.14159265358979
```

**要点**：
- `Client(mcp_server)` 直接传入服务器实例即可内存直连
- 异步上下文管理器自动处理初始化和清理
- 最适合单元测试和快速验证

## 七、场景 5：用 stdio 传输运行 Server + Client

**场景描述**：服务器作为独立进程运行，客户端通过 stdio 管道连接。这是 Claude Desktop 集成的标准方式。

### 服务器代码

```python
# my_server.py
from mcp.server.mcpserver import MCPServer

mcp = MCPServer("My Tool Server")

@mcp.tool()
def greet(name: str) -> str:
    """Greet someone by name"""
    return f"你好，{name}！欢迎使用 MCP！"

@mcp.tool()
def calculate(expression: str) -> str:
    """Evaluate a math expression (safe subset)"""
    allowed = set("0123456789+-*/.(). ")
    if all(c in allowed for c in expression):
        return str(eval(expression))
    return "不支持的表达式"

if __name__ == "__main__":
    mcp.run()  # 默认 stdio 传输
```

### 客户端代码

```python
# my_client.py
import anyio
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client

async def main():
    # 定义服务器启动参数
    server_params = StdioServerParameters(
        command="python",
        args=["my_server.py"],
    )

    # 建立 stdio 连接
    async with stdio_client(server_params) as (read_stream, write_stream):
        async with ClientSession(read_stream, write_stream) as session:
            # 初始化协议握手
            await session.initialize()

            # 列出工具
            tools_result = await session.list_tools()
            print("服务器提供的工具：")
            for tool in tools_result.tools:
                print(f"  [{tool.name}] {tool.description}")

            # 调用工具
            result = await session.call_tool("greet", {"name": "小明"})
            print(f"\n调用 greet: {result.content[0].text}")

            result = await session.call_tool("calculate", {"expression": "2 * (3 + 4)"})
            print(f"调用 calculate: {result.content[0].text}")

anyio.run(main)
```

### 交互输出

```
服务器提供的工具：
  [greet] Greet someone by name
  [calculate] Evaluate a math expression (safe subset)

调用 greet: 你好，小明！欢迎使用 MCP！
调用 calculate: 14
```

**要点**：
- `StdioServerParameters` 指定服务器进程的启动命令
- `stdio_client()` 管理子进程的生命周期
- `session.initialize()` 必须在任何操作前调用

## 八、场景 6：用 Streamable HTTP 传输运行 Server + Client

**场景描述**：服务器通过 HTTP 暴露 MCP 接口，客户端通过 HTTP 连接。适用于远程调用和 Web 集成。

### 服务器代码

```python
# http_server.py
from mcp.server.mcpserver import MCPServer

mcp = MCPServer("HTTP Tool Server")

@mcp.tool()
def search(query: str, max_results: int = 5) -> str:
    """Search for information"""
    # 模拟搜索
    return f"搜索 '{query}' 的前 {max_results} 条结果：\n1. 结果一\n2. 结果二"

if __name__ == "__main__":
    mcp.run(
        transport="streamable-http",
        host="127.0.0.1",
        port=8000,
    )
```

### 客户端代码

```python
# http_client.py
import anyio
from mcp import ClientSession
from mcp.client.streamable_http import streamable_http_client

async def main():
    async with streamable_http_client("http://127.0.0.1:8000/mcp") as (
        read_stream,
        write_stream,
    ):
        async with ClientSession(read_stream, write_stream) as session:
            await session.initialize()

            # 列出并调用工具
            tools = await session.list_tools()
            for tool in tools.tools:
                print(f"发现工具: {tool.name}")

            result = await session.call_tool(
                "search", {"query": "MCP 协议", "max_results": 3}
            )
            print(f"\n搜索结果:\n{result.content[0].text}")

anyio.run(main)
```

### 交互流程

```
# 终端 1：启动服务器
$ python http_server.py
INFO:     Uvicorn running on http://127.0.0.1:8000

# 终端 2：运行客户端
$ python http_client.py
发现工具: search

搜索结果:
搜索 'MCP 协议' 的前 3 条结果：
1. 结果一
2. 结果二
```

## 九、场景 7：结构化输出（Structured Output）

**场景描述**：工具返回结构化数据（Pydantic 模型），客户端可以获取类型安全的 JSON 输出。

### 代码

```python
# structured_server.py
from pydantic import BaseModel, Field
from mcp.server.mcpserver import MCPServer
from mcp.client.client import Client
import anyio

mcp = MCPServer("Weather Server")

class WeatherData(BaseModel):
    city: str = Field(description="城市名称")
    temperature: float = Field(description="温度（摄氏度）")
    humidity: float = Field(description="湿度百分比")
    condition: str = Field(description="天气状况")

@mcp.tool()
def get_weather(city: str) -> WeatherData:
    """Get weather information for a city"""
    # 模拟天气数据
    weather_db = {
        "北京": WeatherData(city="北京", temperature=22.5, humidity=45.0, condition="晴"),
        "上海": WeatherData(city="上海", temperature=25.0, humidity=78.0, condition="多云"),
    }
    return weather_db.get(
        city,
        WeatherData(city=city, temperature=20.0, humidity=50.0, condition="未知"),
    )

async def main():
    async with Client(mcp) as client:
        # 列出工具 - 注意 output_schema 字段
        tools = await client.list_tools()
        for tool in tools.tools:
            print(f"工具: {tool.name}")
            print(f"输出 Schema: {tool.output_schema}")

        # 调用工具
        result = await client.call_tool("get_weather", {"city": "北京"})

        # 文本内容（给 LLM 用）
        print(f"\n文本结果: {result.content[0].text}")

        # 结构化内容（给程序用）
        print(f"结构化结果: {result.structured_content}")
        # {"city": "北京", "temperature": 22.5, "humidity": 45.0, "condition": "晴"}

anyio.run(main)
```

### 交互输出

```
工具: get_weather
输出 Schema: {'properties': {'city': ..., 'temperature': ..., 'humidity': ..., 'condition': ...}, 'type': 'object'}

文本结果: city='北京' temperature=22.5 humidity=45.0 condition='晴'
结构化结果: {'city': '北京', 'temperature': 22.5, 'humidity': 45.0, 'condition': '晴'}
```

**要点**：
- 返回 Pydantic `BaseModel` 会自动生成 `output_schema`
- `result.content` 包含文本表示（给 LLM 读取）
- `result.structured_content` 包含结构化 JSON（给程序使用）
- 支持的类型：`BaseModel`、`TypedDict`、`dataclass`、`dict`、原始类型

## 十、快速上手要点总结

### 三步创建服务器

```python
from mcp.server.mcpserver import MCPServer

# 1. 创建实例
mcp = MCPServer("My Server")

# 2. 注册功能（tool / resource / prompt）
@mcp.tool()
def my_tool(param: str) -> str:
    return f"result: {param}"

# 3. 启动
mcp.run()  # stdio（默认）
# mcp.run(transport="streamable-http")  # HTTP
```

### 三步使用客户端

```python
# 方式 A：内存直连（测试用）
async with Client(mcp) as client:
    result = await client.call_tool("my_tool", {"param": "hello"})

# 方式 B：stdio 传输
async with stdio_client(StdioServerParameters(command="python", args=["server.py"])) as (r, w):
    async with ClientSession(r, w) as session:
        await session.initialize()
        result = await session.call_tool("my_tool", {"param": "hello"})

# 方式 C：HTTP 传输
async with streamable_http_client("http://localhost:8000/mcp") as (r, w):
    async with ClientSession(r, w) as session:
        await session.initialize()
        result = await session.call_tool("my_tool", {"param": "hello"})
```

### 关键记忆点

1. **`MCPServer`** 是唯一需要记住的服务端类
2. **三个装饰器**：`@mcp.tool()` / `@mcp.resource(uri)` / `@mcp.prompt()`
3. **Client** 支持内存直连（传 MCPServer）和远程连接（传 URL）
4. **stdio** 传输用于 Claude Desktop，**HTTP** 传输用于 Web 服务
5. 函数签名自动转换为参数 schema，docstring 自动成为描述
