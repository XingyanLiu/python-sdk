## 一、高频接口速查表

### 服务端 Context API（`ctx: Context`）

在任何 `@mcp.tool()` 或 `@mcp.resource()` 函数中，添加 `ctx: Context` 参数即可自动注入。

| 方法 | 说明 | 使用频率 |
|---|---|---|
| `await ctx.info(data)` | 发送 INFO 级别日志 | ⭐⭐⭐ |
| `await ctx.debug(data)` | 发送 DEBUG 级别日志 | ⭐⭐⭐ |
| `await ctx.warning(data)` | 发送 WARNING 级别日志 | ⭐⭐ |
| `await ctx.error(data)` | 发送 ERROR 级别日志 | ⭐⭐ |
| `await ctx.report_progress(progress, total, message)` | 报告进度 | ⭐⭐⭐ |
| `await ctx.read_resource(uri)` | 读取其他 Resource | ⭐⭐ |
| `await ctx.elicit(message, schema)` | 向用户请求结构化输入 | ⭐⭐ |
| `await ctx.elicit_url(message, url, id)` | 向用户请求 URL 交互 | ⭐ |
| `ctx.session` | 底层 ServerSession 引用 | ⭐⭐ |
| `ctx.request_context.lifespan_context` | 获取 Lifespan 上下文 | ⭐⭐ |
| `ctx.request_id` | 当前请求 ID | ⭐ |
| `ctx.client_id` | 客户端标识 | ⭐ |

### 客户端 Session API

| 方法 | 说明 | 使用频率 |
|---|---|---|
| `await session.initialize()` | 协议握手（必须首先调用） | ⭐⭐⭐ |
| `await session.list_tools()` | 列出所有工具 | ⭐⭐⭐ |
| `await session.call_tool(name, args)` | 调用工具 | ⭐⭐⭐ |
| `await session.list_resources()` | 列出所有资源 | ⭐⭐⭐ |
| `await session.read_resource(uri)` | 读取资源 | ⭐⭐⭐ |
| `await session.list_prompts()` | 列出所有提示 | ⭐⭐ |
| `await session.get_prompt(name, args)` | 获取提示实例 | ⭐⭐ |
| `await session.list_resource_templates()` | 列出资源模板 | ⭐⭐ |
| `await session.complete(ref, argument)` | 自动补全 | ⭐ |
| `await session.send_ping()` | 心跳检测 | ⭐ |
| `await session.set_logging_level(level)` | 设置日志级别 | ⭐ |

## 二、场景 1：Context 上下文 —— 进度报告与日志

**场景描述**：长时间运行的工具需要报告处理进度和操作日志。

### 服务端代码

```python
import anyio
from mcp.server.mcpserver import MCPServer, Context

mcp = MCPServer("Data Processor")

@mcp.tool()
async def process_files(directory: str, ctx: Context) -> str:
    """Process all files in a directory"""
    files = ["data_01.csv", "data_02.csv", "data_03.csv", "data_04.csv", "data_05.csv"]
    total = len(files)
    results = []

    await ctx.info(f"开始处理目录: {directory}")

    for i, filename in enumerate(files):
        # 报告进度
        await ctx.report_progress(
            progress=i,
            total=total,
            message=f"正在处理: {filename}",
        )

        await ctx.debug(f"读取文件 {filename}...")
        # 模拟处理耗时
        await anyio.sleep(0.5)

        results.append(f"{filename}: OK")
        await ctx.info(f"完成处理: {filename} ({i + 1}/{total})")

    await ctx.report_progress(progress=total, total=total, message="全部完成")
    return f"处理完成，共 {total} 个文件:\n" + "\n".join(results)
```

### 客户端代码（带进度回调）

```python
import anyio
from mcp.client.client import Client
from mcp.server.mcpserver import MCPServer

async def main():
    async with Client(mcp) as client:
        # call_tool 支持 progress_callback
        def on_progress(progress, total, message):
            pct = (progress / total * 100) if total else 0
            print(f"[进度] {pct:.0f}% - {message}")

        result = await client.call_tool(
            "process_files",
            {"directory": "/data"},
            progress_callback=on_progress,
        )
        print(f"\n最终结果:\n{result.content[0].text}")

anyio.run(main)
```

### 交互输出

```
[进度] 0% - 正在处理: data_01.csv
[进度] 20% - 正在处理: data_02.csv
[进度] 40% - 正在处理: data_03.csv
[进度] 60% - 正在处理: data_04.csv
[进度] 80% - 正在处理: data_05.csv
[进度] 100% - 全部完成

最终结果:
处理完成，共 5 个文件:
data_01.csv: OK
data_02.csv: OK
data_03.csv: OK
data_04.csv: OK
data_05.csv: OK
```

## 三、场景 2：参数描述与校验 —— Pydantic Field

**场景描述**：为工具参数添加描述信息和默认值，让 LLM 更准确地理解参数含义。

### 代码

```python
from pydantic import BaseModel, Field
from mcp.server.mcpserver import MCPServer

mcp = MCPServer("Email Service")

@mcp.tool()
def send_email(
    to: str = Field(description="收件人邮箱地址"),
    subject: str = Field(description="邮件主题"),
    body: str = Field(description="邮件正文内容"),
    cc: str = Field(description="抄送邮箱（可选）", default=""),
    priority: int = Field(description="优先级 1-5，1 最高", default=3),
) -> str:
    """Send an email to the specified recipient"""
    result = f"邮件已发送:\n  收件人: {to}\n  主题: {subject}\n  优先级: {priority}"
    if cc:
        result += f"\n  抄送: {cc}"
    return result

# 使用 Pydantic BaseModel 定义复杂输入
class DatabaseQuery(BaseModel):
    table: str = Field(description="表名")
    conditions: dict[str, str] = Field(description="查询条件", default_factory=dict)
    limit: int = Field(description="返回记录数上限", default=10)
    order_by: str = Field(description="排序字段", default="id")

@mcp.tool()
def query_database(query: DatabaseQuery) -> str:
    """Execute a database query"""
    return (
        f"查询表 {query.table}，条件 {query.conditions}，"
        f"限制 {query.limit} 条，按 {query.order_by} 排序"
    )
```

### 交互示例

```
# LLM 看到的工具 schema：
# send_email:
#   to (string, required): "收件人邮箱地址"
#   subject (string, required): "邮件主题"
#   body (string, required): "邮件正文内容"
#   cc (string, optional, default=""): "抄送邮箱（可选）"
#   priority (integer, optional, default=3): "优先级 1-5，1 最高"

await client.call_tool("send_email", {
    "to": "user@example.com",
    "subject": "项目进展",
    "body": "本周已完成...",
    "priority": 1,
})
# 返回: "邮件已发送:\n  收件人: user@example.com\n  主题: 项目进展\n  优先级: 1"

await client.call_tool("query_database", {
    "query": {
        "table": "users",
        "conditions": {"status": "active"},
        "limit": 5,
    }
})
# 返回: "查询表 users，条件 {'status': 'active'}，限制 5 条，按 id 排序"
```

## 四、场景 3：Elicitation —— 向用户请求输入

**场景描述**：工具执行过程中需要用户确认或提供额外信息（如预订确认、支付审批）。

### 代码

```python
from pydantic import BaseModel, Field
from mcp.server.mcpserver import MCPServer, Context

mcp = MCPServer("Booking Service")

class BookingConfirmation(BaseModel):
    confirmed: bool = Field(description="是否确认预订？")
    special_requests: str = Field(description="特殊要求", default="")

@mcp.tool()
async def book_restaurant(
    restaurant: str,
    date: str,
    guests: int,
    ctx: Context,
) -> str:
    """Book a table at a restaurant"""
    await ctx.info(f"查询 {restaurant} 在 {date} 的可用性...")

    # 模拟查询
    price = guests * 200

    # 向用户请求确认
    result = await ctx.elicit(
        message=f"找到可用桌位！{restaurant}，{date}，{guests} 位客人，预计消费 ¥{price}。请确认预订：",
        schema=BookingConfirmation,
    )

    if result.action == "accept" and result.data:
        msg = f"预订成功！{restaurant}，{date}，{guests} 人"
        if result.data.special_requests:
            msg += f"\n特殊要求: {result.data.special_requests}"
        return msg
    elif result.action == "decline":
        return "用户取消了预订"
    else:
        return "操作已取消"
```

### 交互流程

```
用户 → LLM: "帮我在 '老北京' 饭店预订明天 4 人的位置"
LLM → Tool: call_tool("book_restaurant", {"restaurant": "老北京", "date": "2025-01-16", "guests": 4})

Tool → 用户 (Elicitation):
  "找到可用桌位！老北京，2025-01-16，4 位客人，预计消费 ¥800。请确认预订：
   - confirmed: [是/否]
   - special_requests: [文本输入]"

用户 → Tool: {"confirmed": true, "special_requests": "靠窗位置"}

Tool → LLM: "预订成功！老北京，2025-01-16，4 人\n特殊要求: 靠窗位置"
LLM → 用户: "已经帮您在老北京饭店预订好了明天的4人桌，靠窗位置。"
```

## 五、场景 4：Sampling —— 从工具内部调用 LLM

**场景描述**：工具需要借助 LLM 的能力来处理请求（如翻译、摘要、分类）。

### 代码

```python
from mcp.server.mcpserver import MCPServer, Context
from mcp.types import SamplingMessage, TextContent

mcp = MCPServer("Smart Assistant")

@mcp.tool()
async def summarize_text(text: str, max_words: int, ctx: Context) -> str:
    """Summarize a long text using LLM"""
    await ctx.info("正在使用 LLM 生成摘要...")

    # 通过 session.create_message 向客户端请求 LLM 推理
    result = await ctx.session.create_message(
        messages=[
            SamplingMessage(
                role="user",
                content=TextContent(
                    type="text",
                    text=f"请用不超过 {max_words} 个字总结以下文本：\n\n{text}",
                ),
            )
        ],
        max_tokens=500,
    )

    if result.content.type == "text":
        return f"摘要：{result.content.text}"
    return "无法生成摘要"

@mcp.tool()
async def classify_intent(user_message: str, ctx: Context) -> str:
    """Classify user intent into categories"""
    result = await ctx.session.create_message(
        messages=[
            SamplingMessage(
                role="user",
                content=TextContent(
                    type="text",
                    text=(
                        "将以下用户消息分类为以下类别之一："
                        "查询、投诉、建议、闲聊。\n\n"
                        f"用户消息：{user_message}\n\n"
                        "请只返回类别名称。"
                    ),
                ),
            )
        ],
        max_tokens=50,
    )

    if result.content.type == "text":
        return f"意图分类：{result.content.text.strip()}"
    return "分类失败"
```

### 交互流程

```
# Sampling 的流转方向:
# Tool → Server → Client（客户端调用 LLM）→ Server → Tool

用户 → LLM: "帮我总结这篇文章..."
LLM → Tool: call_tool("summarize_text", {"text": "...", "max_words": 50})
Tool → Client (Sampling Request): "请用不超过 50 个字总结以下文本..."
Client → LLM: [调用 LLM API 获取回答]
Client → Tool (Sampling Result): "这篇文章主要讨论了..."
Tool → LLM: "摘要：这篇文章主要讨论了..."
```

**注意**：客户端必须提供 `sampling_callback` 才能处理 Sampling 请求：

```python
async def handle_sampling(ctx, params):
    # 这里调用实际的 LLM API
    response = await call_llm(params.messages, params.max_tokens)
    return CreateMessageResult(
        role="assistant",
        content=TextContent(type="text", text=response),
        model="gpt-4",
    )

async with Client(mcp, sampling_callback=handle_sampling) as client:
    result = await client.call_tool("summarize_text", {"text": "...", "max_words": 50})
```

## 六、场景 5：Lifespan —— 管理数据库等外部资源的生命周期

**场景描述**：服务器启动时初始化数据库连接池，关闭时释放资源。

### 代码

```python
from collections.abc import AsyncIterator
from contextlib import asynccontextmanager
from dataclasses import dataclass
from mcp.server.mcpserver import MCPServer, Context

# 模拟数据库客户端
class Database:
    def __init__(self, url: str):
        self.url = url
        self.connected = False

    @classmethod
    async def connect(cls, url: str) -> "Database":
        db = cls(url)
        db.connected = True
        print(f"数据库已连接: {url}")
        return db

    async def query(self, sql: str) -> list[dict]:
        return [{"id": 1, "name": "示例数据"}]

    async def disconnect(self) -> None:
        self.connected = False
        print("数据库已断开")

# 模拟缓存客户端
class Cache:
    @classmethod
    async def create(cls) -> "Cache":
        print("缓存已初始化")
        return cls()

    async def close(self) -> None:
        print("缓存已关闭")

@dataclass
class AppContext:
    db: Database
    cache: Cache

@asynccontextmanager
async def app_lifespan(server: MCPServer) -> AsyncIterator[AppContext]:
    """服务器启动时初始化资源，关闭时清理"""
    db = await Database.connect("postgresql://localhost/mydb")
    cache = await Cache.create()
    try:
        yield AppContext(db=db, cache=cache)
    finally:
        await cache.close()
        await db.disconnect()

mcp = MCPServer("Database Service", lifespan=app_lifespan)

@mcp.tool()
async def query_users(limit: int, ctx: Context) -> str:
    """Query users from database"""
    # 从 lifespan context 获取数据库实例
    app: AppContext = ctx.request_context.lifespan_context
    rows = await app.db.query(f"SELECT * FROM users LIMIT {limit}")
    return f"查询到 {len(rows)} 条记录: {rows}"

@mcp.resource("status://database")
def database_status(ctx: Context) -> str:
    """Check database connection status"""
    app: AppContext = ctx.request_context.lifespan_context
    return f"数据库连接状态: {'已连接' if app.db.connected else '未连接'}"
```

### 交互流程

```
# 服务器启动
$ python db_server.py
数据库已连接: postgresql://localhost/mydb
缓存已初始化

# 客户端调用
await client.call_tool("query_users", {"limit": 10})
# 返回: "查询到 1 条记录: [{'id': 1, 'name': '示例数据'}]"

await client.read_resource("status://database")
# 返回: "数据库连接状态: 已连接"

# 服务器关闭
# 缓存已关闭
# 数据库已断开
```

## 七、场景 6：Image 处理 —— 返回图片数据

**场景描述**：工具需要返回图片（截图、图表、处理后的图片）。

### 代码

```python
from mcp.server.mcpserver import MCPServer, Image

mcp = MCPServer("Image Service")

@mcp.tool()
def generate_chart(title: str, data_points: list[float]) -> Image:
    """Generate a simple chart image"""
    # 使用 matplotlib 生成图表
    import io
    import matplotlib
    matplotlib.use("Agg")
    import matplotlib.pyplot as plt

    fig, ax = plt.subplots()
    ax.plot(data_points)
    ax.set_title(title)

    buf = io.BytesIO()
    fig.savefig(buf, format="png")
    buf.seek(0)
    plt.close(fig)

    return Image(data=buf.read(), format="png")

@mcp.tool()
def create_thumbnail(width: int, height: int) -> Image:
    """Create a placeholder thumbnail"""
    from PIL import Image as PILImage

    img = PILImage.new("RGB", (width, height), color=(73, 109, 137))
    buf = io.BytesIO()
    img.save(buf, format="JPEG")
    buf.seek(0)

    return Image(data=buf.read(), format="jpeg")
```

### 交互示例

```
result = await client.call_tool("generate_chart", {
    "title": "销售趋势",
    "data_points": [10, 25, 18, 35, 42, 38, 55],
})
# result.content[0] 是 ImageContent 类型
# result.content[0].data 包含 base64 编码的 PNG 数据
# result.content[0].mimeType == "image/png"
```

## 八、场景 7：动态增删 Tool

**场景描述**：运行时根据条件动态注册或移除工具（如根据用户权限动态暴露不同工具集）。

### 代码

```python
from mcp.server.mcpserver import MCPServer, Context

mcp = MCPServer("Dynamic Service")

@mcp.tool()
def basic_search(query: str) -> str:
    """Basic search available to all users"""
    return f"搜索结果: {query}"

# 动态添加 admin 工具
def admin_delete(item_id: str) -> str:
    """Delete an item (admin only)"""
    return f"已删除: {item_id}"

@mcp.tool()
async def enable_admin_mode(password: str, ctx: Context) -> str:
    """Enable admin tools"""
    if password == "admin123":
        mcp.add_tool(admin_delete, name="admin_delete", description="Delete items")
        # 通知客户端工具列表已更新
        await ctx.session.send_tool_list_changed()
        return "Admin 模式已启用"
    return "密码错误"

@mcp.tool()
async def disable_admin_mode(ctx: Context) -> str:
    """Disable admin tools"""
    mcp.remove_tool("admin_delete")
    await ctx.session.send_tool_list_changed()
    return "Admin 模式已禁用"
```

### 交互流程

```
# 初始状态
await client.list_tools()
# → [basic_search, enable_admin_mode, disable_admin_mode]

# 启用 admin
await client.call_tool("enable_admin_mode", {"password": "admin123"})
# → "Admin 模式已启用"
# 客户端会收到 ToolListChanged 通知

await client.list_tools()
# → [basic_search, enable_admin_mode, disable_admin_mode, admin_delete]  ← 新增了

# 使用 admin 工具
await client.call_tool("admin_delete", {"item_id": "item-42"})
# → "已删除: item-42"

# 禁用 admin
await client.call_tool("disable_admin_mode", {})
# → "Admin 模式已禁用"
```

## 九、场景 8：变更通知 —— 通知客户端资源/工具更新

**场景描述**：服务端数据变化时主动通知客户端刷新。

### 代码

```python
from mcp.server.mcpserver import MCPServer, Context

mcp = MCPServer("Notification Demo")

data_store: dict[str, str] = {"key1": "value1"}

@mcp.resource("data://{key}")
def read_data(key: str) -> str:
    return data_store.get(key, "not found")

@mcp.tool()
async def update_data(key: str, value: str, ctx: Context) -> str:
    """Update a data entry and notify clients"""
    data_store[key] = value

    # 通知客户端该资源已更新
    from pydantic import AnyUrl
    await ctx.session.send_resource_updated(AnyUrl(f"data://{key}"))

    # 如果是新 key，通知资源列表变化
    await ctx.session.send_resource_list_changed()

    return f"已更新: {key} = {value}"

@mcp.tool()
async def batch_update(updates: dict[str, str], ctx: Context) -> str:
    """Batch update multiple entries"""
    for key, value in updates.items():
        data_store[key] = value
        from pydantic import AnyUrl
        await ctx.session.send_resource_updated(AnyUrl(f"data://{key}"))

    await ctx.session.send_resource_list_changed()
    return f"批量更新了 {len(updates)} 条记录"
```

### 交互流程

```
# 客户端可以订阅资源变更
await session.subscribe_resource("data://key1")

# 更新数据
await client.call_tool("update_data", {"key": "key1", "value": "new_value"})
# 客户端收到 ResourceUpdated 通知 → 可以重新 read_resource("data://key1")

# 批量更新
await client.call_tool("batch_update", {"updates": {"a": "1", "b": "2"}})
# 客户端收到多个 ResourceUpdated 通知 + ResourceListChanged 通知
```

## 十、场景 9：SSE 传输 + Streamable HTTP 选型

**场景描述**：对比不同传输方式，帮助选择最合适的方案。

### Streamable HTTP（推荐 - 生产环境）

```python
# 有状态模式（支持 SSE 流式通知 + 会话管理）
mcp.run(transport="streamable-http", host="0.0.0.0", port=8000)

# 无状态模式（适合负载均衡、Serverless）
mcp.run(transport="streamable-http", host="0.0.0.0", port=8000, stateless_http=True)

# JSON 响应模式（无 SSE 流，纯 JSON 请求/响应）
mcp.run(
    transport="streamable-http",
    host="0.0.0.0",
    port=8000,
    json_response=True,
    stateless_http=True,
)
```

### SSE 传输（兼容旧客户端）

```python
mcp.run(transport="sse", host="0.0.0.0", port=8000)
```

### 选型建议

| 场景 | 推荐传输 | 原因 |
|---|---|---|
| Claude Desktop / 本地工具 | stdio | 简单、安全、零配置 |
| Web 应用 / API 服务 | Streamable HTTP (stateless) | 可水平扩展 |
| 需要实时推送通知 | Streamable HTTP (stateful) | 支持 SSE 流式通知 |
| 需要断线重连 | Streamable HTTP + EventStore | 基于 Last-Event-ID 恢复 |
| 旧客户端兼容 | SSE | 向后兼容 |

## 十二、场景 11：多服务器聚合 —— ClientSessionGroup

**场景描述**：客户端同时连接多个 MCP 服务器，统一管理工具和资源。

### 代码

```python
import anyio
from mcp.client.session_group import ClientSessionGroup
from mcp import StdioServerParameters

async def main():
    async with ClientSessionGroup() as group:
        # 连接多个服务器
        session1 = await group.connect_to_server(
            StdioServerParameters(command="python", args=["math_server.py"])
        )
        session2 = await group.connect_to_server(
            StdioServerParameters(command="python", args=["file_server.py"])
        )

        # 聚合后的工具列表（所有服务器的工具）
        print("所有可用工具：")
        for name, tool in group.tools.items():
            print(f"  {name}: {tool.description}")

        # 统一调用（自动路由到正确的服务器）
        result = await group.call_tool("add", {"a": 1, "b": 2})
        print(f"数学结果: {result.content[0].text}")

        result = await group.call_tool("read_file", {"path": "/tmp/test.txt"})
        print(f"文件内容: {result.content[0].text}")

        # 断开单个服务器
        await group.disconnect_from_server(session1)

anyio.run(main)
```

  multiply: Multiply two numbers          ← 来自 math_server
  read_file: Read a file                  ← 来自 file_server
  write_file: Write a file                ← 来自 file_server

数学结果: 3
文件内容: Hello, World!

## 十三、场景 12：Completions —— 自动补全支持

**场景描述**：为资源模板参数和 Prompt 参数提供自动补全建议。

### 代码

```python
from mcp.server.mcpserver import MCPServer

mcp = MCPServer("Completion Demo")

# 定义自动补全处理器
@mcp.completion()
async def complete_city(name: str, argument_value: str) -> list[str]:
    """Provide city name completions"""
    cities = ["北京", "上海", "广州", "深圳", "杭州", "成都", "武汉"]
    if argument_value:
        return [c for c in cities if argument_value in c]
    return cities

@mcp.resource("weather://{city}")
def get_weather(city: str) -> str:
    return f"{city}: 晴天，25°C"

@mcp.prompt()
def city_guide(city: str) -> str:
    return f"请介绍 {city} 的旅游景点"
```

### 客户端交互

```python
from mcp.types import ResourceTemplateReference

# 自动补全资源模板参数
result = await session.complete(
    ref=ResourceTemplateReference(type="ref/resource", uri="weather://{city}"),
    argument={"name": "city", "value": "北"},
)
print(result.completion.values)  # ["北京"]

# 自动补全 Prompt 参数
from mcp.types import PromptReference

result = await session.complete(
    ref=PromptReference(type="ref/prompt", name="city_guide"),
    argument={"name": "city", "value": "上"},
)
print(result.completion.values)  # ["上海"]
```
